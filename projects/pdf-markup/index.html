PDF 批註工具

在 PDF 上標出需要覆核的區域，配上圖例再匯出，讓接手的同事知道應查看哪個位置。

看重點 ↓

PDF Highlight Studio 載入新建的測試 PDF，畫面保留原工具列、頁面及選區。

成果頁面位置 → 帶標記 PDF

§ 重點

一眼看懂

流程
  1. 讀取頁面在瀏覽器打開 PDF，選取需要註明的位置。
  2. 對齊座標將畫面上的標記換算為頁面座標，配上相應圖例。
  3. 匯出結果批註隨文件一併交付，接收者能按框的位置回看。
工具
  • JavaScript
  • Python
  • PDF
§ 做法

做法細節

系統架構、技術與流程及完整步驟與背景說明。

本機 Python 服務配合瀏覽器介面，保留標記所在的頁面。

架構

組成
本機 Python 伺服器配合瀏覽器介面；pdf.js 負責顯示頁面，pdf-lib 把標記寫回 PDF。
私隱
檔案在本機處理，不上載。

功能

標記
彩色螢光標記，顏色對應標籤類別；可改標籤文字、加文字和白底遮蓋。
座標
畫面上的標記換算為 PDF 頁面座標才寫入，縮放後位置不偏。
