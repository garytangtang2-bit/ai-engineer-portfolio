影音與發佈 · 作品個案

短片排程發佈

以 Python 和瀏覽器自動化串接短片發佈，將預演、排程和執行狀態整理成可重用工具。

打開輸出紀錄 ↓

這個工具在命令列執行，沒有圖形介面；此圖只按本頁步驟整理流程，並非程式畫面。實際輸出可在下方「查看輸出」核對。

成果手動操作 → 排程執行

§ 重點

一眼看懂

流程
  1. 設定輸入準備影片和文案作發佈輸入。
  2. 先做預演按預演流程檢查瀏覽器操作，再由排程啟動。
  3. 記錄狀態保留執行日誌和最後狀態，供後續檢查。
工具
  • Python
  • Selenium
  • Windows 排程

--dry-run預演模式

展開查看選項及對執行的影響。

預演--dry-run

只生成並儲存 caption，不開啟發佈介面。

沿用--skip-gemini

讀取已有的 caption.txt，跳過模型呼叫。

除錯--keep-open

腳本完成後保留 Chrome，方便檢查畫面。
